# Korean Word Definition Lookup Chrome Extension

This extension allows you to hover over a Korean word (while holding Shift) to see its definition in a popup. Definitions are loaded from an external file, which also assigns unique IDs to each word for parsing.

## Features
- Detects hovered word and sentence (Shift+hover)
- Displays a popup with the word’s definition
- Designed for Korean text parsing

## Setup
1. Load the extension in Chrome via `chrome://extensions` (Developer mode > Load unpacked).
2. Provide your definitions file as described in the documentation.
