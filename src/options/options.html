Munmek Settings

Munmek (문맥) is a context-aware Korean popup-dictionary. It performs instant local morphological parsing and dictionary lookups with optional neural sense reranking, optional Ask Gemini AI context explanations, and 1-click Anki flashcard creation.

LLM Contextual Analysis Backend

💡 Local LLM & Self-Hosted Models: Connect to local LLMs (LM Studio, llama.cpp server, Ollama) or any OpenAI-compatible endpoint. No cloud API keys or internet connection required for local servers!
📖 Quick Setup Guide: Local LLM (Speed & Model Recommendations)

1. Recommended Models for Speed & Grammar Nuance:
For instantaneous hover lookups (<500ms), we recommend lightweight ~2B–4B instruction-tuned models with fast tokens/sec:

  • gemma-4-E2B-it-Q4_K_M or gemma-2-2b-it (Ultra-fast, excellent Korean grammar comprehension)
  • llama-3.2-3b-instruct (Very responsive, great JSON schema compliance)
  • qwen2.5-3b-instruct or qwen2.5-7b-instruct (Superb multilingual East Asian language support)

2. Setup in 1 Minute:

  • LM Studio: Load your model, open the Developer / Local Server tab (double-arrow icon), and click Start Server. Keep default URL http://localhost:1234/v1. Ensure CORS is enabled.
  • Ollama: Run ollama run llama3.2. Ollama serves OpenAI-compatible endpoints at http://localhost:11434/v1. (Set OLLAMA_ORIGINS="*" if you encounter CORS issues).
  • llama.cpp: Launch server: llama-server -m your_model.gguf --port 8080 and use URL http://127.0.0.1:8080/v1.

Developer & Experimental Settings

Unlocks experimental definition sense reranking with Multilingual E5 ONNX, WebGPU acceleration, and dictionary vector precomputation.
📦 Optional Model Notice (multilingual_e5_small_int8.onnx):
Stage 2 Cross-Lingual Definition Sense Disambiguation is an optional, experimental feature (~118 MB). To keep the repository lightweight, this model file is not bundled with the source repository.
  • Download from GitHub Releases: Download multilingual_e5_small_int8.onnx from the latest release assets and place it into lib/models/.
  • Or Export Locally: Run python scripts/export_multilingual_onnx.py to export the INT8 ONNX model via Hugging Face Optimum.
Note: If the ONNX model is not present, Munmek operates seamlessly using full-power Kiwi WASM morphological analysis and Stage 0/1 heuristics.
Leverages your GPU for Stage 2 neural embeddings when supported, accelerating multi-definition reranking from seconds down to milliseconds. Automatically falls back to CPU WASM if unavailable.

Dictionary Management & Priority Order

Upload Yomichan KO-EN / KO-JP term bank JSON files or `.zip` archives (e.g., KRDICT-KO-EN.zip) to store offline dictionaries in IndexedDB. Use the Move Up / Move Down controls below to set lookup priority order.
⚡ Precomputed Vector Cache (.vec.bin / .json): Precomputing vectors using GPU hardware accelerates Stage 2 sense reranking for offline lookups (<5ms). Use the step-by-step guide below to generate compact vector cache files in seconds.
📖 Step-by-Step Guide: GPU Vector Precomputation
  1. Install Dependencies: Open a terminal in the project directory and run:
    pip install -r scripts/requirements.txt
  2. Run GPU Precomputation: Execute the script passing your dictionary zip file:
    python scripts/precompute_definition_vectors.py "path/to/dictionary.zip"
  3. Import Vector Cache File: The script outputs [dict_name]_vectors.vec.bin in scripts/ (~79 MB). Click "📥 Import Vector File" next to your installed dictionary below and pick the .vec.bin file!
